# Mahalla by Gōsht: konsept sayt

Statik sayt (HTML/CSS/JS, build yo'q). Lokal ko'rish: `python -m http.server 8796` va http://127.0.0.1:8796

- `index.html`: bo'limlar: hero + 3D burger (skrollda 5 qavatga ajraladi), menyu (narxlar bilan), oshxona videolari, festivallar, 4 filial (Toshkent vaqti bo'yicha "ochiq/yopiq"), yetkazish va katering.
- `js/burger3d.js`: Three.js (unpkg CDN) protsedural burger, modelsiz.
- `js/app.js`: UZ/RU tarjima, menyu tablari, filial holati, videolar.
- `media/`: Instagram (@mahalla_by_gosht) dan olingan suratlar va reels. `ig/`: xom yuklamalar (saytga kerak emas).

Haqiqiy ma'lumot manbai: IG postlar, "Меню Ru" va "График работы" highlightlari.
Ochiq savollar: Ekobozor Beruniy ish vaqti va telefoni, Yandex Eats / Uzum Tezkor havolalari, narxlar dolzarbligi (menyu ~30 hafta oldingi), brend roziligi (`noindex` hozircha yoqilgan).
